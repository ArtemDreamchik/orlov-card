# Orlov — Портфолио фронтенд-разработчика

Персональная визитка и портфолио фронтенд-разработчика и дизайнера сайтов **Саши Орлова**. Одностраничный адаптивный сайт, созданный для привлечения клиентов и демонстрации компетенций.

## 📌 Разделы страницы

- **Главный экран** — краткое представление и позиционирование
- **Портфолио** — карточки последних проектов (Метрика, Nothing, TOPTRIP)
- **Компетенции** — HTML/CSS, JavaScript, библиотеки и фреймворки, адаптивная верстка
- **Услуги** — разработка сайтов под ключ, верстка, мобильный интерфейс
- **Контакты** — форма обратной связи (имя и e-mail)

## ⚙️ Функциональность

- **Burger-меню** — адаптивная навигация для мобильных устройств с ссылками на соцсети
- **Адаптивные изображения** — использование тега `<picture>` с `srcset` для разных разрешений
- **Форма контактов** — поля для имени и электронной почты

## 🛠️ Стек

| Технология | Описание |
|---|---|
| HTML5 | Разметка страницы |
| CSS3 | Стили, адаптивность |
| JavaScript (ES6+) | Burger-меню (ES-модуль) |
| [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) | Шрифт для заголовков |
| [Manrope](https://fonts.google.com/specimen/Manrope) | Шрифт для основного текста |

Без сборщиков и сторонних зависимостей — проект запускается напрямую в браузере.

## 📁 Структура проекта

```
orlov-card/
├── index.html          # Основная страница
├── burger.js           # Логика мобильного меню
├── styles/
│   ├── reset.css       # Сброс стилей
│   └── styles.css      # Основные стили
└── resources/          # Изображения и иконки
```

## 🚀 Запуск

Никакой установки не требуется. Просто открой `index.html` в браузере:

```bash
# Клонируй репозиторий
git clone https://github.com/ArtemDreamchik/orlov-card.git

# Перейди в папку проекта
cd orlov-card

# Открой index.html в браузере
# (или запусти локальный сервер, например через VS Code Live Server)
```

> **Рекомендуется** открывать через локальный сервер (например, расширение [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) в VS Code), чтобы ES-модуль `burger.js` (`type="module"`) работал корректно.
